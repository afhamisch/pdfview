# Extra fonts

Drop TrueType (.ttf), OpenType (.otf) or WOFF (.woff) files in this folder and
rebuild. They appear in the Text tool's font list and are embedded (subset) into
saved PDFs. Variants are recognized from the file name: `Bold`, `Italic` or
`Oblique`, `BoldItalic`; a file with none of these is the regular weight.
Example: `BookAntiqua.ttf`, `BookAntiqua-Bold.ttf`, `BookAntiqua-Italic.ttf`,
`BookAntiqua-BoldItalic.ttf`.

Open fonts bundled from npm at build time: Tinos (Times New Roman metrics),
Arimo (Arial metrics), Cousine (Courier New metrics), EB Garamond, Crimson Pro,
Libre Baskerville, DejaVu Sans and DejaVu Serif.
